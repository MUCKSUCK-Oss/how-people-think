# Healthcare: when the trick comes from a doctor

- **The situations (308 decisions):**
  - H1 (India): a stent or medicines for stable chest pain.
  - H2 (USA): an early MRI for back pain.
  - H3 (USA): a community hospital or a private-equity-owned luxury hospital for childbirth.
- **Files:** [`RESEARCH.md`](RESEARCH.md) · [`PREDICTIONS.md`](PREDICTIONS.md) · [`RESULTS.md`](RESULTS.md) · `health.py` · `analyse_health.py combined`
- **Key result:** a doctor's "ticking time bomb" raised stent choices from 43% to 64%, while a scary clinic ad *lowered* MRI choices.
