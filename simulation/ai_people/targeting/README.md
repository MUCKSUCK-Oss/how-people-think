# Personal targeting: loan apps and personalised prices

- **The situations (182 decisions):**
  - P1 (India): an instant-loan app when ₹15,000 is needed by tomorrow.
  - P2 (USA): booking a flight now vs comparing prices.
- **Files:** [`RESEARCH.md`](RESEARCH.md) · [`PREDICTIONS.md`](PREDICTIONS.md) · [`RESULTS.md`](RESULTS.md) · `targeting.py` · `analyse_tgt.py combined`
- **Key result:** desperation beats information (honest loan terms changed nothing for people ashamed to ask family). Ads written for the individual added nothing, and "others pay $279" cut booking from 43% to 14%.
