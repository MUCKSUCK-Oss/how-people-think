# Earbuds pilot (first test of the method, superseded)

The first test of AI people, on 10 Nov 2026: 20 AI shoppers choose between two earbuds, with and without a default or a scarcity message. It was run before the research-first rule was adopted, and it is kept for the record.

- `earbuds.py`: the pilot.
- `earbuds_v2.py`: a larger design that was never run; its persona builder is reused by `../classics/`.
- `analyse_earbuds.py`: the analysis.
